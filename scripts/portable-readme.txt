日程通 SchedFlow 便携版（解压即用）　版本 {VER}
==================================================

■ 这是什么
  免安装版本：解压后直接运行 schedflow.exe 即可使用，无需安装、无需管理员权限，
  适合无权安装软件的电脑（公司 / 学校机器）。安装包版本照常保留：
  SchedFlow_{VER}_x64-setup.exe（src-tauri\target\release\bundle\nsis\ 下）。

■ 使用方法
  1. 把整个 SchedFlow-{VER}-portable 文件夹解压到任意位置（U盘 / 桌面 / 任意盘）。
  2. 双击 schedflow.exe 运行。
  3. 首次运行若提示 "Windows 已保护你的电脑"，点「更多信息」→「仍要运行」
     （未签名 exe 的正常提示，不影响使用）。

■ 系统要求
  · Windows 10 / 11（64 位）。
  · 需要 WebView2 运行时：Windows 11 自带；Windows 10 一般随系统更新自动装好。
    若双击无反应或白屏，请在可联网的机器上安装一次「WebView2 Runtime」
    （微软官网搜索，或 Windows 更新补丁），之后即可长期免安装使用。

■ 数据存放位置
  日程 / 待办数据保存在 %APPDATA%\com.schedflow.app 目录（系统隐藏目录），
  与安装版共用同一份数据——安装版 / 便携版之间切换不丢数据。
  彻底清除数据：退出程序后删除该目录。

■ 与安装版的区别
  · 无开始菜单 / 桌面快捷方式，不出现在「应用与功能」列表。
  · 应用内「开机自启」仍可用（写入当前用户注册表）；受限账户若写入失败会提示。
  · 功能、数据、提醒、悬浮球与安装版完全一致。
